# ADR 0024：真实感客厅质量标杆

## 状态

已采纳。

## 背景

上一版暖木实时样板补齐了卧室、厨房、卫生间和基础软装，但客厅仍混用低面数 Kenney 茶几、
程序化电视柜、纯色地毯与项目生成绿植。模型轮廓、表面反射和空间层次没有达到客户交付预期，
整屋鸟瞰也无法证明房间近景质量。

## 决策

先建立一间可复用的客厅质量切片，再把同一套资产准入和灯光材质规则推广到其他房间：

1. 客厅主要可见物件改用固定、可审计的 Poly Haven CC0 模型，包括茶几、木柜、小型绿植和
   陶瓷摆件；保留原作者材质，不再用风格色覆盖纹理。挂画模型进入目录但在缺少可靠墙面锚点
   前不自动摆放，避免生成悬空装饰。
2. Poly Haven 1K glTF 的每个依赖继续按字节数和 MD5 固定，导入报告记录 SHA-256；运行时 GLB
   将较大贴图缩至 512 px，使全部模型目录保持在 5 MiB 移动端预算以内。
3. Viewer 复用高清渲染链路已有的 Lebombo HDRI 与木地板 PBR 贴图，并增加 512 px 天然织物
   地毯材质。API 在启动时校验文件后，通过 `/render-assets` 提供同源资源。
4. 房间近景采用更接近眼平高度的相机和更低的邻墙遮挡，整屋模式仍保留完整结构。
5. 客厅配方同时覆盖沙发、茶几、地毯、电视柜、大绿植、台面绿植、花瓶和吊灯，避免
   只替换单件模型却继续呈现空场景。

## 结果

资产目录升级为 v5，18 组 fixture 布置中引用的模型约 3.18 MiB，完整模型目录约 3.64 MiB；
实时页面拥有 HDR 环境反射、木地板颜色/法线/粗糙度、天然织物地毯和 15 个已加载真实模型。
这是一条客厅质量标杆，不代表所有房间已经达到最终照片级交付；后续应按同一准入规则替换
卧室床头柜、餐厅家具，并补充窗帘和更匹配暖木风格的现代沙发。
