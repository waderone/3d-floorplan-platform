# ADR 0026：卧室、厨房与卫生间真实感对齐

## 状态

已采纳。

## 背景

ADR 0024 和 ADR 0025 已把客厅提升为当前实时 3D 的质量标杆，但卧室仍缺少床头功能层，
厨房和卫生间的组合模型细节、地面材质、局部灯光及近景构图明显落后。桌面镜头可用，
手机竖屏进入房间时还可能裁掉主体家具。

## 决策

1. 资产目录升级为 v7，项目原创室内模型生成器升级为 v2。新增带台灯的石材床头柜；
   厨房补齐烤箱、烟机、水槽、灶具、台面陈设和柜底灯；卫生间补齐镜框镜灯、浴室柜抽屉、
   淋浴控制、毛巾架、马桶按钮和淋浴底盘。四份 GLB 均固定字节数与 SHA-256。
2. layout 升级为 `multiroom-opening-clearance-layout-v6`。三间卧室均布置床、单侧床头柜/台灯、
   地毯和吊灯；紧凑房型继续满足房间边界、墙体和门洞净空。
3. Viewer 为卧室、厨房和卫生间使用独立主体镜头，近景只显示当前房间家具，并降低遮挡建筑
   的不透明度。暖木厨房使用石材地面，卫生间使用带勾缝的浅色石材地砖，并增加主体局部光。
4. 房间镜头半径按画布宽高比自适应，390×844 竖屏会拉远而不是裁掉床、橱柜或洁具。
5. 模型请求 URL 带目录 SHA-256，目录二进制更新后绕过旧静态资源缓存。

## 结果

暖木真实样板保持 6/7 空间已布置，三间卧室、厨房和卫生间达到与当前客厅一致的实时展示标准。
完整模型目录为 3,925,608 字节，低于 5 MiB 移动预算；390×844 和 1280×720 均无页面溢出，
三套装修风格可实时切换，浏览器无警告或错误。这里的“对齐”指实时模型层次、灯光、材质和
可用近景达到同一产品阶段，不宣称达到离线 Cycles 照片级最终效果图。
