# ADR-0027：商业级实时卧室质量标杆

## 背景

上一阶段证明卧室、厨房和卫生间可以在同一真实户型中实时布置，但卧室近景仍由圆角盒式床品
承担视觉焦点。继续批量复制该模型会放大返工，因此先把卧室 1 做成可评审样板，用用户确认过的
单房间标准冻结后续资产、材质、灯光和构图要求。

## 决策

1. 保留现有 layout item、碰撞体、房间锚点和紧凑房间降级规则，只替换最高级可见资产。
2. 项目自有床组升级为 23 个部件：可垂坠被面、床尾搭毯、四只枕头、腰枕、软包床架、分缝床头
   和床脚。床品使用 Poly Haven Cotton Jersey CC0 的 diffuse、normal、roughness，导入时缩为
   512 px 并内嵌到 GLB。
3. 床模型采用 `tint`。装修风格只乘算织物角色色，不丢失作者纹理、法线和粗糙度，因此同一几何
   可在暖木极简、北欧浅色、现代深色之间实时切换。
4. 新增项目自有 29,860 B 浮雕画，使用真实画框、分层几何和暖木配色；吊灯移到床侧，避免遮挡
   床头焦点。
5. 卧室相机从床尾侧观察，宽屏半径限制为 3.8～4.1 m。房间聚焦继续隐藏相邻家具并降低建筑
   遮挡，不把剖切式实时 3D 伪装成离线室内摄影。
6. 两个生成器都把修改器产生的顶点和 UV 量化到 `1/4096` 米/纹理单位，独立运行两次必须得到
   相同字节和 SHA-256。完整模型目录继续受 5 MiB 移动端硬预算约束。

## 验收结果

- 商业床 GLB 为 718,584 B，内嵌三张 512 px PBR 织物图；浮雕画为 29,860 B。
- 完整模型目录为 4,565,028 B，小于 5,242,880 B。
- 床和浮雕画各自独立生成两次，交付 SHA-256 完全一致。
- 真实项目卧室 1 已在 1280×720 页面验证床品褶皱、软包床头、枕头层次、床尾搭毯、床侧吊灯
  和浮雕画完整可见。
- 暖木、北欧、现代三套风格都能加载同一床组；现代深色会切换为深灰织物，北欧保持明亮浅色，
  PBR 表面细节不丢失。
- API 目录/布局定向测试、Viewer 逻辑测试和生产构建通过。

## 后续边界

本阶段只提供卧室质量样板，不立即批量改写其他房间。用户确认该标准后，厨房、卫生间和其余
卧室按同一原则升级：先确定视觉焦点和可复用高质量资产，再做表面材质、局部照明、房间构图与
移动端预算回归。
