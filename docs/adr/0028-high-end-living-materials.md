# ADR-0028：高端移动端暖木客厅材质标杆

## 状态

已接受，2026-07-24。

## 决策

首个高质量交付切片只升级暖木极简客厅的可见材质，不同时修改其他房间、其他风格、灯光烘焙或离线打包架构。

- 保留 Sofa 01 已有的作者 1K PBR 材质。
- Modern Coffee Table 01 与 Modern Wooden Cabinet 从项目内 512 px 降采样版本恢复为作者 1K PBR 交付。
- Curly Teddy Natural 地毯从 512 px 恢复为已审计的 1K diffuse、normal、roughness 三通道。
- 木地板与地毯在 Viewer 中启用 16 倍各向异性过滤，改善斜视和近景纹理稳定性。
- 完整 GLB 模型目录的硬上限由面向低端全屋加载的 5 MiB 调整为面向高端手机演示的 8 MiB；当前实际为 7,279,848 B。

## 边界

本阶段不宣称已经达到最终商业效果图。它冻结的是“暖木客厅材质清晰度”标准；下一阶段仍需独立解决灯光烘焙、接触阴影、软装细节、质量档位与可离线缓存的客户预览包。
