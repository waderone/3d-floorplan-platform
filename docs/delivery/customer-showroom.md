# 客户 3D 样板间交付说明

## 已交付能力

当前商业演示包使用一套已复核真实户型，默认打开暖木极简客厅近景，并支持：

- 鼠标、触控、缩放、旋转和全屏浏览；
- 全屋、鸟瞰、客厅近景、三间卧室、厨房和卫生间视角；
- 现代深色、北欧浅色、暖木极简三套风格实时切换；
- 桌面、平板和高端手机高画质展示；
- 完全脱离开发 API 的本地或同一 Wi-Fi 预览；
- 逐文件 SHA-256 完整性核验。

这是商业演示版/MVP，不是已完成鉴权、多租户、云存储和生产监控的公网 SaaS。

## 直接使用交付 ZIP

解压 `refined-commons-190205778-showroom.zip` 后：

- macOS：双击 `启动预览.command`。如系统首次阻止，右键该文件并选择“打开”。
- Windows：双击 `启动预览.bat`。
- 通用方式：在解压目录运行 `python3 启动预览.py`。

终端会显示电脑地址：

```text
http://127.0.0.1:4173/
```

手机或平板与电脑连接同一 Wi-Fi，再访问终端显示的局域网地址。不要直接双击
`index.html`，`file://` 无法可靠加载模块和 3D 资源。

默认是干净客户界面和高端画质。需要查看完整工程统计或恢复自动画质时，在地址后添加：

```text
?mode=full&quality=auto
```

## 从仓库重新生成

先构建 Viewer：

```bash
cd apps/viewer
npm run build
cd ../..
```

再从 ready 项目生成确定性 ZIP：

```bash
work/api-venv/bin/python tools/delivery/package_showroom.py \
  --project-id refined-commons-190205778 \
  --output dist/delivery/refined-commons-190205778-showroom.zip
```

命令会打印输出路径、ZIP 字节数和 SHA-256。相同源码、项目数据、风格和资产再次执行时，ZIP
哈希必须一致。

## 完整性核验

核验整个 ZIP：

```bash
shasum -a 256 dist/delivery/refined-commons-190205778-showroom.zip
```

解压后，`bundle-manifest.json` 记录包内每个文件的相对路径、字节数和 SHA-256，可用于上传、
复制、归档或交付后的逐文件检查。

## 演示建议

1. 使用高端手机、平板或带独立显卡/Apple Silicon 的电脑。
2. 首屏保留暖木极简客厅近景，先让客户查看沙发、茶几、灯具、地毯和材质。
3. 再切换现代深色和北欧浅色，说明结构与家具布局不变、风格实时替换。
4. 使用全屋或鸟瞰解释空间关系，再进入卧室、厨房和卫生间。
5. 如需跨网络分享，应部署到受控 HTTPS 静态服务器；本地启动器只面向本机和可信局域网。

## 已知边界

- 当前只冻结了一套真实复核户型作为质量标杆，不能据此宣称任意户型都能零人工修正。
- 暖木客厅是最高质量主展示风格；现代和北欧已可切换，但不是三套完全独立采购的家具资产包。
- 预览包是浏览器实时渲染，不等同于离线 Cycles 照片级静帧。
- 正式外部交付前仍需按客户图纸逐套确认原图权利、房间语义、门窗和人工复核状态。
